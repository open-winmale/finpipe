# finpipe：API 文档瘦身为核心接口 + Swagger/OpenAPI

背景量化：底层函数 155 个中 L1 辅助/筛选类占 95 个（kline 38、bonus 33…），文档现在收录 126 个——长尾过重。核心接口 = 友好层 **31 个方法**（四大类全覆盖）+ 11 个指标组。注：第三方对标名不进仓库（铁律+门禁），本计划所有产出只含中性表述。

## 1. 新增 `tools/gen_openapi.py` → `docs/openapi.json` + `docs/swagger.html`

- **31 个核心接口 → 语义化路径**（如 `POST /kline/bars`、`/statements/income`、`/indicator/get`）：
  - 参数 schema 从方法签名自动提取（`inspect.signature`；注解是字符串形式，写小解析器支持 str/int/float/bool/list[str]/X | None）
  - summary/description 从 docstring 提取（首行 summary，`:param n: …` 行转参数说明）
  - 返回 schema 从底层函数的目录 `returns_shape` 映射（FRIENDLY_INDEX 第 5 列可回溯到底层函数时；`$CODE eval` 等不可映射的给通用 object）
  - tags = 四大类中文；operationId = `{ns}_{method}`
- **一条真实网关路径** `POST /v1/analysis/xs/eval`（tag「网关」）：SDK 的真实 HTTP 层，body schema 固定文档化；语义化路径的 description 注明由 SDK 封装、实际经网关执行
- servers 指向 api.winmale.com；securitySchemes = bearerAuth（OAuth client_credentials 取 token）
- `docs/swagger.html`：单文件 Swagger UI（CDN），加载同目录 openapi.json，可浏览/可导入 Apifox、Postman
- **漂移门禁**：`gen_openapi.py --check` 进 test_drift.py
- 共享逻辑抽 `tools/_introspect.py`（方法签名/docstring 解析），gen_api_docs 与 gen_openapi 共用
