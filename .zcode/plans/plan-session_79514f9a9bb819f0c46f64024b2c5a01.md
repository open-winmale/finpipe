# finpipe 文档优化：把数据优势讲清楚（且每条都有目录依据）

## 写作原则（先定调，避免踩仓库门禁）
- **“完全免费”限定为非商业用途**：许可证是 PolyForm Noncommercial，写“个人学习/研究等非商业使用完全免费”，否则与 LICENSE 冲突。
- **不写任何具体额度数字**：仓库无依据，截图的 2,000/时、20,000/天 是你当前 Pro 档，不代表新用户默认额度。统一写“注册即得免费额度，个人研究足够用；具体额度以开放平台为准”。
- **免费与体验 appid 分开说**：自己的 appid = 免费且额度充足；内置体验 appid = 共享池、仅供初次体验（保留现有诚实表述）。
- **不提任何第三方产品名**（check_leak 强制）；不写 Level2、历史分时、全市场覆盖等目录明确否定的能力。
- 经营数据口径如实写：有“合并/母公司、单期/多期/TTM、披露原值/派生指标、收入按地区构成、运营效率与费用率”；**产品线/业务分部口径一期未纳入**（公开目录确无）。

## 1. README.md（主阵地，手写）
重构为“卖点 → 能力详解 → 口径速查 → 凭证/额度”：

- **首段**：A 股数据 SDK；免费额度充足；pip 装完即用；目录随包、离线可查；类型化 IDE 补全。
- **新增「为什么选择 finpipe」**（6 条，各一句）：
  1. 非商业使用完全免费，注册即得充足免费额度
  2. 开箱即用：内置体验 appid，`Client()` 零配置（正式使用换自己的）
  3. 目录随包：155 底层函数 / 32 核心接口 / 2197 指标代码，离线可查、有类型补全
  4. 口径显式：原始数据 vs 指标逐函数标注；单位统一
  5. 财报按最新会计准则归一（新旧准则适配在平台内部完成）
  6. 覆盖面完整：K线、财报、分红、公告、业绩、资金流、指标
- **新增「数据能力详解」**：9 个域逐段（每段 3–5 句 + 关键能力列表），重点展开你点名的三项：
  - **K 线**：不复权/前复权/后复权；最新一根；盘中快照（单票/批量）；当日 1 分钟分时（有损采样，非逐笔）；ETF 日线；指数点位桥接；均线/事件筛选；回测光标语义；单位=元/手/小数
  - **分红**：历史明细（预案/实施）；每股分红；窗口合计与次数；TTM 股息率/派息率（小数，0.0396=3.96%）；质量筛选
  - **财报**：三大表多期透视；合并 vs 母公司及差额；树视图含派生比率行；审计意见；新旧准则归一；金额=报表原币
  - 其余：资金流、指标层（11 组/2197 代码）、公告（含回购/减持/增持/激励信号+证据行）、定期报告清单（PDF 链接）、业绩预告/快报/披露日历、股本与档案
- **新增「口径速查」表**：维度｜可选值｜说明
  复权（nr/qfq/hfq）· 报表范围（合并/母公司/差额）· 期间（单期/多期/TTM）· 性质（原始/指标）· 单位（价格元、量手、percent 小数、指标 pct 百分数、分红率小数）· 时间窗口（7d…5y 或天数）· 会计准则（已归一）
- **改造「凭证与 AppID」**为「免费额度与凭证」：先讲免费额度充足，再讲三步申请（保留现有步骤），最后讲不配置时用体验 appid（额度有限、共享）。
- 许可证段加一句：“免费”指非商业用途；商业需授权。
